## 수정한 계약

```text
스탯 원값 S = 코어 적용 기초 스탯 + 장비 고정 수치 + 큐브 고정 수치 + 소장품 고정 수치
버프 목록 = OL 비율 + 액세서리 비율 효과 + 현재 유효한 스킬 비율
개념식: 공격력 = S × (1 + OL 공증 + 스킬 공증 + ...)
정수화: S + Σ동일수치그룹 round(S × (비율 × 중첩 수), AwayFromZero)
타격 공방차 = 위 공격력 − 적용 적 방어력
```

공증 목록은 **합친 뒤** 그룹화한다. 서로 다른 수치까지 하나로 뭉쳐 한 번 반올림하지 않으며, OL과 스킬을 따로 반올림한 뒤 더하지도 않는다. 공격력 증가와 B3의 공격 대미지 증가는 별개다. 차지식과 히트 정수화 후보는 유지한다.

### 계산 자료형과 정수화

- 공격력·장탄수 및 타격 피해 계산의 비율·중간값은 `double` 대신 **부호 있는 `long` 기반 고정소수점**으로 전환하는 방향을 채택한다. 음수 버프·디버프·방어력 차감이 있으므로 `ulong`으로 대체하지 않는다. 통계의 평균·분산 등 모든 실수 필드를 일괄 정수화하라는 뜻은 아니다.
- 원천 비율이 1/10000 단위 정수이면 그 값을 유지한다. 예: 14.5%는 `1450 / 10000`. 입력 경로별 정밀도·범위를 확인하고, 더 정밀한 값을 조용히 잘라내지 않는다.
- 공격력·최대 장탄수는 `기본값 + Σ round(기본값 × 동일 버프율 × 개수)`를 유지한다. 서로 다른 비율을 합쳐 한 번 반올림하거나, 동일 비율의 중첩을 각각 반올림하지 않는다. 사사오입은 음수 경계도 포함해 검사한다.
- 차지 시간의 기존 1/100초 정수 연산을 보존한다. 시전자 기준 고정량 부여·고정 장탄 증가 등 별도 효과의 기준도 유지한다.
- B2·B3·B4·B5 등 타격 배율에도 같은 정밀도 보존 원칙을 적용하되, 선택된 피해 정책의 **합산·곱셈 순서와 내림·반올림 위치를 변경하지 않는다**. 정수 나눗셈으로 중간 소수부를 조기에 버리지 않는다. 자료형 변경으로 미확정 게임 정수화 규칙을 확정하지 않는다.
- 곱셈·합산·형 변환 등 위험 연산에 `checked`를 적용한다. `long`의 최대값은 `9,223,372,036,854,775,807`이다. 충분한지는 최종 피해뿐 아니라 실제 중간값으로 확인한다.
