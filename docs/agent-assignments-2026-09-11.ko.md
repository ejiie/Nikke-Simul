## 공통 기능 계약의 의미

### damage log

- 기본 대상 앨리스(5004), 지원 편성 내 다른 니케도 선택 가능. 실제 피해 확정 경로에서 기록하며 별도 재실행으로 대체하지 않는다.
- 시간(프레임과 초), 발사/명중 식별자, 공격자·대상·효과·피해 종류, 개별 피해, 누적 피해를 구분한다. 다중 명중을 발사 수로 잘못 집계하지 않는다.
- 실제 차지 비율·풀차지 여부·실효 차지 시간, 크리티컬·코어, 팀 풀버스트 상태와 시전자 자신의 버스트 효과 활성 상태를 구분하여 기록한다. 현재 사용하지 않는 필드를 임의의 참값으로 채우지 않는다.
- 공격력·적용 방어력·계수·차지 배율·관련 버프와 반올림 정책 등 발당 검산 근거를 제공한다. 버프 출처와 유효 시점을 보존한다.
- 로그 ON/OFF가 피해·사격·난수 소비를 바꾸지 않아야 한다. 일반 debug trace 한도와 분리하고, 대상의 180초 기록이 조용히 잘리지 않도록 한다. 제한이 불가피하면 완전성/잘림 상태와 이유를 명시한다.
- 저장·내보내기에는 계정/계산/런타임 스냅샷 식별자, 규칙·스키마 버전, 실행 조건을 포함한다. 과거 로그 미수집과 실제 피해 0을 구별한다.

### 버스트 tactic

- 사용 허용 목록과 우선순위를 분리한다. 사용 제외 니케는 next_ready 대체 후보에도 포함되지 않는다.
- I→II→III 단계 순서는 유지한다. 같은 단계 안의 후보 우선순위와 III단계 순환/첫 시전자를 설정한다.
- 우선 후보 미준비 시 wait_preferred / next_ready 의미를 명시한다. III 교대가 대체 사용·단계 만료 시 어떻게 전진하는지도 계약/테스트로 고정한다.
- 현재 편성에 없는 ID, 중복, 잘못된 단계, 불가능한 실행 구성을 명시적으로 검증한다. 기존 불완전 편성의 초안 저장 가능성과 실행 가능성을 혼동하지 않는다.
- 구버전 입력과 저장 결과는 기존 의미를 유지한다. 새 설정은 명시적으로 버전 구분하고, 재조회·재실행에 필요한 설정을 보존한다.
