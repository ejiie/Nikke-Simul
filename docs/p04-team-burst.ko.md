# P04 — 팀 게이지·자동 버스트

2026-09-11. 현재 규칙 버전 `p04.team.2` (풀차지 배율 정정). 지원 범위는 기존 리타·블랑·누아르·앨리스·모더니아의 스킬 그래프다. 기계적 실행 검증과 실게임 정확도 검증을 구분하며 `gameVerified=false`를 유지한다.

## 사용자 결정: 모더니아 교체 무기

사용자 확인: 모더니아 버스트의 무기 교체는 15초 지속이고 풀버스트도 총 15초다. 다음 게이지 충전 구간에는 기본 무기로 복귀한다. 따라서 교체 shot 1026002의 게이지 수치 확보는 P04 선행 조건에서 제외한다.

별도 기록만 유지할 항목: 1026002의 범위·다중 타깃·교체 무기 고유 발사 필드와 실측 대미지. 기존 실행기는 확보된 스킬 계수·RPM·무제한 탄약·15초 모드를 사용한다. 시전과 풀버스트 진입 사이의 지연 때문에 무기 모드는 풀버스트보다 먼저 종료될 수 있으며, 두 타이머를 근거 없이 합치거나 연장하지 않았다. 게이지 충전은 종료 후 기본 shot 기준으로 재개한다.

## 적용한 게이지 모델

현재 모델은 `source_full_charge_v2`다. 풀차지 배율은 사용자 확인식으로 정정했다. 단계 전이와 나머지 게이지 적용 범위의 실측 대조는 계속 구분한다. 이전 `einkk_normal_hit_v1` 모델은 폐기했으며 새 실행 입력으로 받지 않는다.

- 최대 게이지: 고정 런타임의 `gaugeConstants.capacityRaw` (현행 1,000,000).
- 단계 0에서 평타 명중 이벤트마다 충전. 발사·탄 소비·직접 스킬·추가타는 별도로 더하지 않는다.
- 대상이 stage target이면 `target_burst_energy_pershot`, 아니면 `burst_energy_pershot`을 선택한다. 두 수치를 더하지 않는다. 현 솔로 레이드 대상은 stage target으로 입력한다.
- 명중 이벤트가 이미 펠릿 1개·대상 1개를 뜻하므로 shotCount/muzzleCount를 다시 곱하지 않는다. 실제 파츠 다중 명중 생성은 P05 범위다.
- 풀차지 평타 명중은 선택된 기본 충전값 × `full_charge_burst_energy / 10000`으로 계산한다. 자동/직접 조작 모두 동일하다. 솔로 레이드 앨리스는 `56000 × 35000 / 10000 = 196000`이다. 대미지용 차지 배율이나 공통 2.5배를 사용하지 않는다.
- 풀차지 여부는 실제 발사 결과의 `FullCharge`로 판정한다. 비풀차지는 기본 충전값을 사용하며 부분 차지 선형 보간은 추가하지 않는다. 차지 무기에 원천 배율이 없으면 임의 기본값 대신 입력 오류로 처리한다. 소수 게이지 정수화는 기존 후보의 반올림을 유지한다.
- `full_charge_burst_energy`는 총 배율 필드로 사용한다. ConfigBattle의 `ulti_gauge_*`는 여전히 별도 보존하며 용도가 확인되지 않은 상수를 추가 합산하지 않는다.
- 상한을 넘는 충전은 잘라내며 발생량과 실제 반영량을 별도로 합산한다. 가득 차면 I단계로 넘어가고 다음 발사부터 충전하지 않는다. I/II/III 대기와 풀버스트 중에도 충전하지 않는다.
- 풀버스트 종료 후 단계 0·게이지 0으로 재개한다. 충전 중 미확인 shot이 발생하면 기본값으로 대체하지 않고 실행을 실패시킨다. 모더니아 교체 shot을 찾기 위한 별도 작업은 하지 않는다.

## 상태 전이·시전자 선택

`충전 → I → II → III → 풀버스트 → 종료 → 재충전`을 `ISkillBattleDriver`와 `ICombatEventSink`로 연결한다. 기존 `TryCast/GetCooldown/TryEnterFullBurst`를 사용한다. 쿨다운 사본이나 고정 충전시간을 만들지 않는다.

- 기본 시전자: 편성 순서의 준비된 니케. 버스트 III에는 사용자 지정 순환 우선순위가 가능하다.
- 사용 불가 정책: `next_ready`는 준비된 대체 니케를 사용하며 `wait_preferred`는 우선 니케를 기다린다.
- I단계는 사용 가능할 때까지 대기한다. II/III의 대기 기한은 앞 시전자의 원천 burst_duration을 사용하고 만료하면 재충전한다. 현재 모든 단계가 10초로 같다고 하드코딩하지 않는다.
- 단계 간 조작 지연 기본값은 1~10프레임 균등 표본, III→풀버스트는 28프레임이다. 기존 사용자 프로젝트 T02 기록에서 가져온 비교 정책이며 이번 작업의 신규 실측값은 아니다. API 입력에 명시적으로 저장한다. 원천 burst_apply_delay보다 앞서 진행하지 않는다.
- 버스트 스킬 시전과 풀버스트 진입은 별도 이벤트다. 지속시간은 마지막 시전자 요청을 사용해 **진입부터** 계산한다. 모더니아는 총 900프레임이며 추가 900프레임이 아니다.
- 리타의 진입 쿨감과 블랑의 종료 조건은 기존 효과 엔진에서 처리하고 다음 단계가 갱신된 상태를 조회한다.
- 시전으로 인한 별도 사격 정지는 기존 사용자 결정에 따라 추가하지 않는다.
- 단계 재진입·AllStep 캐릭터는 현재 5인에 없으며 지원 완료로 표시하지 않는다. 현 범위를 벗어난 전이 프로파일은 거부한다.

## 저장·UI

기존 Local Lab 스타일의 솔로 레이드 검산 화면을 확장했다. 기본 모드는 자동 사이클이며, 기존 1회 지정 시점과 버스트 미사용도 비교용으로 유지한다. 자동 입력과 지정 시간표의 혼용은 엔진에서 거부한다.

결과는 기존 immutable skill-replays 저장소에 `kind=team_burst_replay`로 남는다. 계정 스냅샷·계산 및 런타임 버전·적용 레벨·무기/스킬 입력과 함께 자동 정책, 게이지 원천 상수, 원인 trace ID별 충전량, 시전·쿨다운·대기, 풀버스트 구간과 구성원별 구간 대미지를 저장한다. 전체 구성원/effect 대미지는 기존 결과 계약을 유지한다.

타임라인에는 별도 상한이 있으며 잘림 여부를 기록한다. 상세 로그를 끄거나 상한에 도달해도 게이지·사이클·대미지 집계는 계속 실행한다. UI의 충전 기여 %는 전투 전체 누적 게이지이며 100%를 초과할 수 있다.

## 2026-09-11 충전 규칙 재검토 — 이전 정확도 설명 정정

사용자 지적 후 원천 blabla_roledata.json의 192명 중 차지 시간 또는 full_charge_burst_energy가 있는 76명을 전수 비교했다. 분포는 25,000: 68명, 35,000: 5명, 20,000: 2명, 15,000: 1명이다. 앨리스/유니 35,000, 맥스웰 25,000, 홍련: 흑영 15,000, 신데렐라/베스티: 택티컬 업 20,000을 확인했다. 전체 값과 원천 hash는 ignored artifacts/p04/charge-audit/raw-charge-fields.json에 저장했다.

P04 구현 당시에는 이 비교를 하지 않았다. 참조 코드의 공통 1+1.5*r를 개별 full_charge_burst_energy 검증 없이 채택했으며, 캐릭터별 차이를 버린 근거 부족한 선택이었다. 앞서 안내한 앨리스 수동 풀차지 충전량 140,000을 게임 적용값으로 사용할 근거는 없으므로 철회한다. 자동/직접 조작 구분 역시 원천 적용 규칙을 재확인해야 한다.

원천 숫자의 단위, 총 배율/가산 배율/충전량 의미, 부분 차지 보간, 조작 조건을 확인하기 전에 다른 식으로 임의 교체하지 않는다. 현행 p04.team.1 결과는 이 결함을 포함하는 이전 후보 결과다. 141개 테스트와 180초 11회 기록은 구현 내부 동작 검증이며 이 충전 규칙의 게임 정확도 근거가 아니다. 이 기록 추가 시점에는 실행 코드를 변경하지 않았다.


## 풀차지 정정 적용

사용자 확인에 따라 위 현재 규칙을 적용했다. 과거 p04.team.1 저장 결과는 변경하거나 재계산 결과로 덮어쓰지 않는다. 새 결과는 p04.team.2/source_full_charge_v2로 구별한다. 이전의 11회 사이클과 140,000 안내는 현재 규칙의 검증 결과가 아니다.

정정 검증: 엔진 테스트 91개 통과. 원천 풀차지 배율 15000/20000/25000/35000을 자동·수동에서 각각 확인하고, 비풀차지 보너스 제외·누락 배율 거부·구버전 모델 요청 거부를 검증했다. 저장 스펙 180초·정수화 3후보에서 앨리스의 모든 충전 대상 풀차지 명중이 196000임을 확인했다. 저장·재조회, 로그 on/off 일치, 실행본 배포 후 동일 결과와 계정/스펙/편성 hash 보존 확인. 현재 근거: ignored artifacts/p04/charge-verification/. 구버전 검증 파일은 덮어쓰지 않았다.
