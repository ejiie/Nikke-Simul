1. **무기군 칸**: 무기군 이미지(이미 있는 `weapon-*.png`) + 무기군 텍스트로 표시.
2. 열 제목의 **"(다수)" 삭제**: "적정 사거리(다수)" → "적정 사거리".
3. 예외 칸의 캐릭터: **이름은 한글**로(예: "Harran" → "하란"), **캐릭터 코드(#5042 등)는 UI에 노출하지 않는다.** (현재 표는 공개 roster 영어 이름과 코드를 그대로 보여준다.)
4. 하단 문구 **삭제**: "무기군 표는 참고용이며 판정은 캐릭터별 값을 씁니다(예외 캐릭터 반영). 원천 Database/raw/blabla_roledata.json · sha256:… · 실게임 검증 전".

## R3~R8 — 솔로 레이드 "전투 조건" 정리 (접수)

사용자 캡처: 전투 조건 = 시간(초) 180 · 적 방어력 "30,925 · 누적 20억 전" · 크리티컬 "끔" · 대미지 정책 "클라이언트 float32(기본)" · 샷건 계수 "발사 1회" · 코어 명중 · 적정 거리 · 약점 + 안내 문구.

- **R3 시간 삭제:** UI에서 시간 입력을 없애고 **180초 고정**.
- **R4 방어력 자동 전환:** UI에서 적 방어력 선택을 없앤다. **한 덱(한 전투)의 누적 대미지가 20억 이하이면 DEF 30925, 20억을 넘기면 그 이후 31784.** 사용자 예: 5덱 누적 대미지(억) `{10, 15, 25, 5, 7}` → 10·15·5·7 덱은 끝까지 30925, 25 덱은 30925로 시작해 누적 20억 초과 시점부터 31784.
  - 해석(잠정, 실험 후보): 전환 기준은 덱 단위 팀 누적 대미지 **> 2,000,000,000**. 20억을 넘기게 만든 타격 자체는 30925로 계산하고 그 다음 타격부터 31784. 같은 프레임 여러 타격은 엔진의 기존 프레임 내 순서를 따른다. 이 경계 처리는 문서에 가설로 남긴다.
  - 기존 "고정 DEF 30925" 실험·통계와 섞이지 않게 규칙 버전·fingerprint를 분리한다. 안내 문구("방어력은 이번 검산 전체에 고정… 자동 전환은 아직 적용하지 않습니다")도 새 동작에 맞게 바꾼다.
- **R5 크리티컬 유지:** 선택은 남기되 **기본값을 "확률 적용"**으로(현재 캡처는 "끔").
- **R6 대미지 정책 유지:** 지금은 남긴다. **정책이 확정되는 순간부터 UI에서 제거**한다(확정 시점은 실측 대조 결과로 결정).
- **R7 샷건 계수 삭제:** UI에서 없애고 **"발사 1회"(per_trigger)로 고정**.
- **R8 보스 선택:** 크리티컬·대미지 정책 **아래**에 보스 선택을 만든다. Nikke-Local-Lab UI를 참조한다. 목록은 **더미 보스 + 실제 솔로 레이드 보스들**, 보스 이미지는 **enikk.app/soloraid**에서 가져온다.
  - **보스 이름은 한국어로 표시한다**(사용자 추가 요구, 2026-09-29). 한국어 원천에서 가져오며 영문 이름을 임의 번역·추측하지 않는다. 한국어 이름이 없는 보스는 누락 사유를 명시한다. 2026-09-29 사용자 추가 지시: 37시즌 "울트라(수냉솔레)"의 괄호 문구 제외, 빠진 33시즌은 웹 검색(공지·나무위키 등)으로 찾는다.

적용 범위: 솔로 레이드 "전투 조건". 단일 덱 통계 화면의 같은 조건도 같은 규칙을 쓰는 것으로 본다(두 화면이 조건을 공유).
