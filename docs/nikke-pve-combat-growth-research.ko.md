조사일: **2026-09-09**. 목적은 Nikke-Simul의 전투 모델과 솔로 레이드 육성 평가에 필요한 게임 규칙을 이해하는 것이다. 스토리 내용, 아레나/PvP, 캐릭터 취향·모집 티어표는 제외했다. 캠페인·일일 콘텐츠는 육성 재료와 기능 해금의 연결만 다룬다. 이번 작업은 조사·기록이며 엔진이나 UI를 변경하지 않았다.

## 2. 기본 전투: 무엇이 대미지와 사이클을 결정하는가

### 편성과 조작

기본 편성은 5인이다. 각 캐릭터는 클래스(화력형·방어형·지원형), 무기, 코드, 버스트 단계와 쿨다운, 두 일반 스킬과 버스트 스킬을 가진다. 클래스는 성장 스탯·장비 호환에 관여하지만 실제 역할은 스킬에 의해 결정된다. 버스트 I을 전부 힐러, III을 전부 개인 딜러로 분류하면 편성 평가를 잘못하게 된다. [캐릭터 성장](https://www.prydwen.gg/nikke/guides/character-progression/), [기본 편성](https://www.prydwen.gg/nikke/guides/team-building/)

전투에서는 조작 캐릭터의 조준·차지·엄폐와 자동 사격을 함께 고려한다. 자동 버스트의 위치 우선순위도 편성 순서와 연결된다. 수동으로 짧게 차지해 연속 사격하거나, 저지·파츠를 먼저 조준하거나, 다음 공격에 맞춰 버스트를 보류하면 같은 스펙으로도 결과가 달라진다. ‘자동/수동’ 두 값만으로 모든 조작을 표현하기는 부족하다. [수동 전투 분석](https://nikke.gg/manual-play-guide/)

### 무기 6종

아래 표의 오른쪽은 **시뮬레이터에서 따로 보존해야 하는 상태**다. 고정된 무기별 DPS 순위가 아니다. 무기 분류는 [무기 가이드](https://www.prydwen.gg/nikke/guides/weapon-types/), 세부 입력은 현재 확보한 캐릭터별 공식 자료와 C# 발사 모델을 대조했다.

| 무기 | 전투에서 볼 요소 | 필요한 모델 |
|---|---|---|
| AR 소총 | 연사, 탄 퍼짐, 적정 거리, 코어 조준 | 발사 간격·탄착·장탄·재장전 |
| SMG 기관단총 | 많은 발사와 실제 명중의 차이 | 발수와 명중 수 분리, 탄 퍼짐 변화 |
| MG 머신건 | 연사 준비와 유지, 사격 중단 손실 | 연사 상태·중단/재개·재장전·탄 보충 |
| SG 샷건 | 한 번의 사격에서 여러 펠릿 판정 | 탄 소비 1회와 펠릿별 명중/크리/코어 분리 |
| SR 저격소총 | 차지, 풀차지 조건, 관통 여부, 수동 조작 | 부분/풀차지·전이 시간·관통 경로 |
| RL 런처 | 차지와 폭발, 본체·파츠 중복 명중 | 직격 대상·폭발 범위·각 대상 판정 |

발사체 수, 펠릿 수, 차지시간, 재장전 방식, 연사 한계는 캐릭터별 값이다. ‘RL은 무조건 1발’, ‘SR은 모두 1초’, ‘SG는 언제나 같은 펠릿 수’ 같은 일반화는 사용하지 않는다. 명중률 증가는 크리티컬 확률 증가와 다르며, 탄 퍼짐과 실제 대상 크기를 거쳐 명중·코어 적중에 영향을 준다. [명중률 용어](https://nikke.gg/frequently-asked-questions/)

### 적과 생존

보스의 본체, 파츠, 코어, 저지 부위, 투사체는 같은 대상이 아니다. 파츠 파괴로 타격 대상 수가 줄거나 보스 패턴이 바뀔 수 있다. ‘관통 활성’이라는 버프만 있다고 본체·파츠가 자동으로 모두 맞는 것도 아니다. 위치와 관통 경로가 필요하다. **코어 히트의 코어는 육성의 코어 강화와 무관하다.**

엄폐는 별도 HP와 노출 상태를 가지며, 회복·보호막·불굴과 서로 다른 역할을 한다. 엄폐 전환으로 이미 조준된 투사체를 피하는 현상을 모든 공격에 통하는 무적으로 모델링하면 안 된다. 공격 판정과 이동한 피격 위치가 맞지 않는 경우를 구분해야 한다. [엄폐·투사체 회피 분석](https://www.prydwen.gg/nikke/guides/advanced-combat-mechanics/)

설계상 생존은 단순한 통과 조건에 그치지 않는다. HP 조건 버프, 사격 중단, 타깃 선정, 스킬 발동과 연결된다. 힐러의 개인 대미지가 낮아도 팀의 사격·버스트 유지 시간을 늘릴 수 있다.

## 3. 버스트: 팀 공용 상태로 이해한다

일반적인 흐름은 **게이지 충전 → 버스트 I → II → III → 풀버스트 → 재충전**이다. 기본 풀버스트는 통상 10초지만 연장·단축, 단계 재진입·변경 등 예외를 가진 캐릭터가 있으므로 스킬 자료로 결정해야 한다. 쿨다운 20초/40초는 흔한 구성이며 모든 캐릭터의 상수는 아니다. 한 단계의 사용자가 준비되지 않으면 게이지가 차 있어도 다음 사이클을 원하는 때에 돌리지 못한다. [기본 버스트 편성](https://www.prydwen.gg/nikke/guides/team-building/)

게이지는 단순히 준 대미지에 비례하지 않는다. 명중, 다중 대상, 무기·캐릭터의 생성량 및 스킬 효과를 구분해야 한다. 짧은 차지 사격으로 충전을 앞당기는 운영이 가능한 이유도 여기에 있다. 과거 실험은 보스·구조물 명중과 다중 명중을 구분했고, 차지 비율에 비례한 게이지 증가를 부정했다. 다만 2023년 표의 개별 수치는 현재 공식 데이터와 다시 대조할 비교 자료다. [버스트 게이지 원 실험](https://nikke.gg/burst-gauge-generation/)

현재 5인 그래프가 이미 요구하는 이벤트도 서로 다르다.

| 구분 | 현재 대상에서의 예 | 혼동하면 생기는 오류 |
|---|---|---|
| 탄 소비 | 블랑의 120발 조건 | 빗나간 탄을 제외하거나 SG 펠릿을 여러 발로 셈 |
| 평타 명중 | 모더니아의 명중 기반 효과 | 추가타를 다시 평타로 발행해 재귀 발동 |
| 특정 버스트 사용 | 리타의 자기 버스트 그룹 조건 | 다른 동료의 시전도 자기 누적 횟수로 셈 |
| 풀버스트 진입 | 리타 쿨감, 누아르 탄 보충 | 버스트 I 시점에 미리 효과 적용 |
| 풀버스트 종료 | 블랑의 종료 조건 효과 | 진입과 종료를 같은 이벤트로 취급 |
| 체력·동료·상태 조건 | 누아르·앨리스·블랑 | 상시 버프로 만들어 생존·편성 영향을 삭제 |

이 구분의 근거는 [현재 5인 공식 그래프 조사와 실행 계약](p03-skill-runtime.ko.md)이다. **개인 버스트 스킬의 지속시간과 팀 풀버스트의 지속시간도 별도 상태**로 보존해야 한다.

## 4. 스탯과 대미지는 서로 다른 계산 단계다

### 스탯 조립

공식 블라블라 코드와 현재 C#을 대조한 조립 구조는 다음과 같다. 이것은 각 단계의 정수화 위치를 생략한 개요이며, 이 식으로 기존 코드를 다시 단순화하라는 뜻이 아니다.

```text
레벨별 스탯 + 돌파의 비율/고정 증가 + 호감도 + 해당 콘솔
    → 코어 강화 적용
    → 장비·큐브·소장품의 고정 HP/ATK/DEF 추가
    = 스탯 원값

스탯 원값 + 유효한 비율 버프 기여 + 별도 고정 증가량
    = 해당 시점의 전투 스탯
```

코어 강화의 2%를 장비·큐브를 모두 더한 마지막 값에 일괄 곱하지 않는다. 현재 계산은 [StatCalculator.cs](../src/Nikke.Core/Stats/StatCalculator.cs), 공식 비교 근거는 [블라블라 스탯 모듈](https://www.blablalink.com/assets/nikke/version/default/assets/cube-icon-CVdKq4Pn.js)에 있다.

OL 공격력과 같은 기준의 스킬 공증은 공통 버프 합산에 들어간다. 사용자가 정한 예시대로 원값 100, OL 20%, 공증 50%이면 170이다. 100×1.2×1.5=180으로 처리하지 않는다. 동일 수치 그룹의 중첩·반올림은 현재 검증된 C# 규칙을 보존한다. 시전자의 공격력에 비례해 동료에게 주는 증가량은 수혜자 자신의 공격력 비율과 구분한다. [OL 정정·검증 기록](p02-buff-correction.ko.md), [StatBuffCalculator.cs](../src/Nikke.Core/Stats/StatBuffCalculator.cs)

**시전자 기준 공격력 xx%의 공증량은 시전자의 스탯 공격력 원값을 기준으로 계산하며, 시전자의 OL 공증 옵션은 이 공증량을 올리지 않는다.** 예를 들어 시전자 스탯 공격력 500, 지급 비율 14%이면 증가량은 70이다. 시전자에게 OL 공증 20%가 있어도 84로 늘어나지 않는다. 장비 강화 등으로 스탯 공격력 원값이 증가하는 경우와 OL 비율 옵션을 변경하는 경우를 분리한다. 사용자 정정(2026-09-09)과 [현재 시전자 공증 경로](../src/Nikke.Engine/Skills/SkillReplay.cs)를 기준으로 명시한다.

### 한 타격의 계산 축

정수화 전 개념 구조는 다음과 같다. 실제 적용 여부는 타격 종류별로 결정한다.

```text
(유효 공격력 − 유효 방어력)
× 해당 공격의 계수
× 차지 배율
× (1 + 적용되는 크리·코어·풀버스트·적정 거리 보너스의 합)
× 적용되는 대미지 증가군
× 적용되는 받는 대미지 증가군
× 우월 코드 배율
```

크리 기본 확률 15%, 크리 보너스 50%, 일반적인 코어 보너스 100%, 풀버스트 50%, 적정 거리 30%, 코드 우위 기본 10%는 기본값을 설명하는 수치다. 캐릭터·무기·효과 예외가 있으며, 크리·코어·풀버스트·거리 보너스를 각각 독립 곱으로 만들면 안 된다. 우월 코드 보너스는 상성 조건이 필요하다. 진짜 대미지는 방어력 무시, 지속·분배·관통 등의 대미지는 각 적용 범위를 따로 다룬다. [대미지 분석과 적용 범위](https://nikke.gg/damage-formula/)

차지는 **`기본 × (1 + 배율 증가분 합) + 가산 합`**으로 유지한다. 예를 들어 기본 350%, 배율 증가 10%, 가산 20%라면 405%다. 407%가 되는 `(350%+20%)×1.1`과 다르다. 소장품의 차지 대미지 배율 증가와 일반 차지 대미지 증가는 다른 축이라는 분석과도 일치한다. [소장품 차지 실험](https://nikke.gg/collection-item-guide-and-overview/)

불확실한 것은 타격 정수화, 부분 차지, 같은 프레임의 적용 순서 등이다. 현재 [HitCalculator.cs](../src/Nikke.Core/Combat/HitCalculator.cs)는 3개 정수화 후보를 비교한다. 기초 스탯 오차 0을 이유로 이 후보 중 하나를 확정하지 않는다.

## 5. 육성 체계와 재료의 흐름

### 캐릭터·계정 성장

| 성장 축 | 실제로 바뀌는 것 | 레이드 평가에서의 의미 |
|---|---|---|
| 레벨·싱크로 | 레벨 테이블에서 읽는 HP/ATK/DEF | 레벨 고정 모드에서는 계정 표시 레벨과 전투 적용 레벨을 분리 |
| 한계돌파 | 돌파 스탯, 일반 레벨 및 호감도 상한 | 별 수와 현재 레벨을 별도 보존 |
| 코어 강화 | 돌파 후 추가 성장 | 별 3개를 유지하고 코어 1부터 별도 표시 |
| 호감도 | 클래스별 고정 HP/ATK/DEF | 대화 내용은 필요 없고 레벨·증가량만 필요 |
| 스킬 1·2·버스트 레벨 | 계수·버프량·지속·기능상 임계점 | 세 슬롯을 독립 평가, 일괄 10레벨 대입 금지 |
| 리사이클 룸 콘솔 | 계정 공통/클래스/기업 단위 스탯 | 한 캐릭터의 장비처럼 중복 소유하지 않음 |
| 장비 강화·OL | 고정 스탯 및 전투 버프 | 부위 강화와 옵션 재설정의 효과·비용을 구분 |
| 큐브 | 고정 스탯, 상시/조건부 효과 | 계정 큐브 레벨과 캐릭터 장착을 분리 |
| 소장품·애장품 | 고정 스탯, 무기 효과, 생존, 스킬 교체 | 단순한 추가 공격력 칸으로 표현 불가 |

SSR은 한계돌파 3회 뒤 코어 강화 1~7로 이어진다. SR은 최대 2회 돌파, R은 돌파 불가이므로 희귀도별 제약이 필요하다. 일반적인 호감도 상한은 비필그림 30, 필그림 40이며 돌파 조건과 개별 캐릭터 가능 여부를 함께 확인한다. [성장 체계](https://www.prydwen.gg/nikke/guides/character-progression/), [호감도와 증가 스탯](https://www.prydwen.gg/nikke/guides/bond-ranks)

돌파·코어 강화에는 같은 캐릭터의 중복 획득으로 얻는 스페어 바디 등이 사용된다. SSR의 직접 육성 상한은 3돌파에서 160→200으로 올라가고, 싱크로의 160 제한을 넘기려면 기준이 되는 5명의 성장이 필요하다. 5명을 200까지 성장시킨 뒤의 싱크로 육성은 배치 캐릭터에 공유되므로 모든 캐릭터의 코어를 올려야 200 이상을 사용할 수 있는 구조가 아니다. 스킬은 세 슬롯을 각각 1~10레벨로 강화하며, 캐릭터 레벨 초기화와 스킬 재료 환급은 별개다. [현재 성장 설명](https://www.prydwen.gg/nikke/guides/character-progression/), [싱크로와 160 제한](https://nikke.gg/beginners-guide/)

싱크로는 초기에는 상위 5명의 최저 레벨을 배치 캐릭터에게 공유하며, 200 이후에는 장치 성장으로 이어진다. 싱크로 상한이나 제거 대기시간을 오래된 가이드의 고정값으로 넣지 않는다. 현재 가이드 중에도 과거 최대 468이라는 설명과 800 이상 재료표가 함께 남아 있었다. [싱크로·육성 개요](https://nikke.gg/beginners-guide/), [레벨 재료표의 시점 혼재 사례](https://www.prydwen.gg/nikke/guides/level-requirements)

### 재료를 어디서 얻는가

다음은 재료 공급의 큰 연결이다. 일일 횟수·해금 스테이지·교환 가격·드롭 확률 전체를 현행 확정표로 만들지는 않았다.

| 공급원 | 연결되는 육성 |
|---|---|
| 전초기지 방어·일반 진행 보상·이벤트 | 크레디트, 배틀 데이터, 코어 더스트 등 레벨 재료 |
| 시뮬레이션 룸·오버클럭 등 | 스킬/버스트 강화 재료; 코드 매뉴얼 등 별도 재료도 필요 |
| 요격전 | 장비, 강화 재료, 상위 장비·OL 관련 재료 |
| 로스트 섹터 | 큐브와 관련 강화 재료 |
| 유니온 보상·상점 | 큐브 배터리 등의 공급 |
| 파견·솔로 레이드 | 소장품·관리 키트·애장품 관련 재료 |
| 솔로 레이드 뮤지엄 | 과거 보스 전투 및 소장품 관리 재료 획득 경로 |
| 리사이클 관련 재료·교환 | 공용·클래스·기업 연구 |

공급 연결은 [기본 육성/일일 콘텐츠](https://nikke.gg/beginners-guide/), [큐브 획득·배터리](https://www.prydwen.gg/nikke/guides/harmony-cubes-information/), [소장품 공급](https://www.prydwen.gg/nikke/guides/collection-intro)을 대조했다. 뮤지엄의 존재·도입 이력은 [공식 배포 앱의 버전 기록](https://apps.apple.com/us/app/goddess-of-victory-nikke/id1585915174)에서도 확인된다. 뮤지엄과 현재 시즌 솔로 레이드의 보스 규칙·보상을 같은 것으로 가정하지 않는다.

따라서 성장 비용은 하나의 숫자로 합치기보다 크레디트·강화 재료·커스텀 모듈·배터리·관리 키트 등 자원별 벡터로 보존하는 편이 적절하다. 환산 기준이 없는 서로 다른 재료를 임의로 동일 가치로 계산하지 않는다.

## 6. 장비와 오버로드를 어떻게 이해해야 하는가

장비는 머리·몸통·팔·다리 4부위이며 클래스 호환과 기업 일치가 중요하다. 기업이 맞는 T9 장비를 +5까지 강화한 뒤 커스텀 모듈로 OL 전환하고 다시 강화한다. OL 장비에는 최대 3줄의 추가 효과가 붙고 장착 캐릭터에 귀속된다. 다른 덱 캐릭터에게 자유롭게 옮길 수 있는 공용 옵션으로 취급하면 안 된다. [OL 전환 구조](https://www.prydwen.gg/nikke/guides/overload-gear-intro/)

이 프로젝트에서 보존할 옵션은 공격력, 방어력, 우월 코드, 최대 장탄, 명중률, 차지 속도, 차지 대미지, 크리티컬 확률, 크리티컬 대미지다. 한국어 표시 명칭은 Local Lab UI·공식 데이터의 기존 매핑을 따른다. 아래는 옵션 평가 시 구분할 효과다.

| 옵션 성격 | 평가할 변화 |
|---|---|
| 공격력 | 자신의 전투 공격력과 대미지 변화. 시전자 기준 공격력 xx%의 공증량에는 OL 공증이 영향을 주지 않음 |
| 우월 코드 | 해당 보스의 코드 상성과 적용 타격 |
| 장탄 | 재장전 감소, 발수 조건 도달, 마지막 탄 조건 지연 |
| 명중률 | 명중·코어 적중·명중 조건 스킬의 변화 |
| 차지 속도 | 차지 완료 시각, 버프 창 안의 발수, 프레임 임계점 |
| 차지 대미지 | 기본 차지에 대한 가산 축; 배율 증가와 구별 |
| 크리 확률/대미지 | 평균뿐 아니라 편차와 목표 대미지 초과 확률 |
| 방어력 | 생존·스탯 기반 스킬·대상 선정 변화 |

이 표는 기존 공식 효과 분류와 런타임에 근거한 **평가 설계**다. ‘항상 공증 우선’, ‘방어 옵션은 언제나 무가치’, ‘장탄은 무조건 많을수록 좋음’ 같은 절대 추천은 만들지 않는다.

재설정은 서로 다른 행동이다.

| 행동 | 바뀌는 것 |
|---|---|
| 옵션 변경 | 잠금되지 않은 줄의 옵션 종류·수치 및 줄 생성 결과 |
| 수치 재설정 | 기존 옵션 종류를 유지하고 수치 변경; 빈 줄에 새 옵션이 생기는 행동이 아님 |
| 지속 잠금 | 해제하기 전까지 해당 줄 보존 |
| 임시 잠금 | 한 번의 재설정에서 해당 줄 보존 |
| 결과 유지/적용 | 새 결과를 보고 이전 결과 보존 또는 새 결과 채택 |

2025-11-19 갱신된 재설정 분석에는 임시 잠금이 명시되어 있다. 잠근 줄 수에 따른 재설정 비용 증가도 설명한다. **종류 변경과 수치 재설정, 잠금 재화, 새 결과를 거절할 선택을 모두 모델링**해야 한다. 이 자료의 추천 최소 수치나 ‘최상위 1%’ 문구를 공식 확률표 자체로 사용하지는 않는다. 줄별 생성률·옵션 중복 제약·등급별 확률·현재 잠금 비용은 현행 게임 안내/원천 표 확보 후 버전별로 고정할 대상이다. [OL 변경·수치·잠금 실험 및 설명](https://www.prydwen.gg/nikke/guides/overload-gear-reroll/)

향후 추천의 한 단계 목적함수는 다음처럼 정의할 수 있다.

```text
현재 장비 상태 s에서 행동 a를 시도
→ 가능한 결과 s'의 확률 분포
→ 각 s'에서 5덱을 다시 평가/재배치
→ 유지와 적용 중 더 나은 선택의 가치
→ 현재 5덱 가치 대비 기대 증가량과 자원별 소모량
```

한 번 시도의 효율과 여러 번 시도해서 목표 옵션에 도달하는 비용은 다른 문제다. 수치가 임계점에 못 미친 현재의 낮은 효율만으로 장기 경로를 제외하면 안 된다. 지원 캐릭터의 스킬 강화·스탯 공격력 원값 증가 등 실제 동료 효과를 바꾸는 육성도 평가한다. 시전자 기준 공증량이 늘어난다는 이익을 OL 공증 옵션 변경에 부여하지 않는다.

## 7. 큐브·소장품·애장품

**큐브는 계정 성장과 캐릭터 장착을 함께 가진다.** 한 캐릭터는 하나를 장착하며, 큐브 성장에 따라 여러 캐릭터에게 장착 가능한 범위가 변한다. 큐브별 배터리로 레벨을 올리고 고정 스탯과 고유 효과를 얻는다. 재장전 단축과 일정 탄 소비 후 탄 회복은 같은 효과가 아니다. [큐브 구조](https://www.prydwen.gg/nikke/guides/harmony-cubes-information/)

이번에 읽은 공식 카탈로그는 16종이다. 예를 들어 `cube-1000303.json`의 **렐릭 베어 큐브**는 고정 ATK/HP/DEF 배열과 재장전 속도·우월 코드 효과를 별도로 제공한다. `level1/level2/level3`는 효과 단계 매핑이므로 큐브 레벨을 효과 수치 배열의 인덱스로 바로 사용하지 않는다. 카탈로그에 존재한다는 사실은 계정 보유·레벨·장착 가능 인원의 증거가 아니다. [공식 리소스를 읽는 현재 어댑터](../tools/data-pipeline/account_presentation_assets.py)

소장품은 무기 계열에 맞춰 장착하며 R/SR 등급과 성장 단계가 있다. 고정 스탯 외에 AR의 코어, MG의 장탄, SR/RL의 기본 차지 배율, SG/SMG의 평타 계수처럼 효과 축이 다르다. 관리에는 대성공과 R→SR 경험치 이전이 있어 투입 키트 수와 얻는 단계가 선형 관계가 아니다. [소장품 효과·관리 실험](https://nikke.gg/collection-item-guide-and-overview/)

애장품은 모든 캐릭터의 공통 강화가 아니다. 대응 캐릭터의 **호감도 30 + SR 소장품 15단계** 등을 갖춰 전환하고, 이후 3개 단계에서 스킬이 바뀐다. 일반적인 진입 조건인 2돌파를 3돌파·코어 1로 잘못 올려 잡지 않는다. 전환 가능 여부와 현재 애장품 단계는 별도로 저장하고 그 단계의 스킬 그래프를 선택해야 한다. [애장품 조건과 단계](https://www.prydwen.gg/nikke/guides/collection-intro)

설계상 소장품의 피해 감소·엄폐 HP도 포함할 필요가 있다. 개인 평타 증가량만 계산하면 생존에 필요한 육성을 무효한 투자로 판단할 수 있다. 큐브 장착 한도는 현재 계정 입력 계약에서 충분히 확보했는지 추가 확인할 항목이다.

## 8. 솔로·유니온 레이드와 통계의 의미

솔로 레이드는 여러 덱을 사용하고 이미 사용한 캐릭터를 중복 편성할 수 없는 구조다. 챌린지는 레벨을 고정하는 규칙이 있으므로 일반 전투의 계정 레벨을 그대로 사용하면 안 된다. 기존 안내는 챌린지 400레벨과 최대 5덱을 설명하지만, 현재 대상의 실제 모드·레벨·제한시간은 시나리오에 명시해 검증해야 한다. [솔로 레이드 기본 규칙](https://www.prydwen.gg/nikke/guides/solo-raid)

유니온 레이드는 유니온이 공유하는 보스 진행과 개인의 제한된 사용 기회를 함께 가진다. 이 프로젝트의 목표는 비중복 3덱이지만, 솔로 5덱에서 단순히 2개를 빼는 문제가 아니다. 서로 다른 보스·잔여 HP·필요 처리시간에 맞춘 배정이 필요할 수 있다. 오래된 가이드의 라운드·난이도·보스 목록을 현행 규칙으로 고정하지 않는다. [유니온 레이드 원 분석](https://nikke.gg/union-raid-information-and-mechanics/)

현재 사용자가 정한 실측 대상은 솔로 챌린지 보스이고, **누적 20억 전 방어력 30,925 / 후 31,784**다. 이는 해당 관측 대상의 조건이며 모든 솔로 보스의 공통 방어력이 아니다. 정확한 경계 타격에 어느 방어력이 적용되는지도 별도 검증한다. [사용자 측정 조건](p03-measurement-guide.ko.md)

통계와 최적화는 다음처럼 구분하는 것이 적절하다. 아래는 게임 자료에서 인용한 규칙이 아니라 프로젝트 목표를 수학적으로 해석한 것이다.

- 덱별 전투 대미지를 X, 목표 대미지를 d로 놓고 `P(X ≥ d)`를 추정한다. ‘상위 a%’는 확률 a와 그에 해당하는 대미지 분위값을 구분해서 표시한다.
- 평균·표준편차만으로 정규분포를 가정하지 않는다. 생존 실패·버스트 누락·파츠 파괴로 분포가 갈라질 수 있어 경험적 분위수·초과 확률·신뢰구간도 필요하다.
- 같은 조건의 독립 시도에서 성공 확률 p라면 성공까지 기대 시도 수는 `1/p`, 성공 전에 실패하는 기대 횟수는 `(1-p)/p`다. 고정 한 번 소요시간 t와 재시작 비용 r이면 기대 총시간은 `t/p + r(1-p)/p`다. 조기 종료 정책에서는 실제 실패/성공 소요시간을 따로 측정한다. p=0을 유한 재시도 시간으로 표시하지 않는다.
- 개별 최상위 덱 5개를 순서대로 뽑으면 강한 공용 서포터를 한 덱에 소모해 전체 합계가 나빠질 수 있다. 캐릭터 중복 금지 하에서 **5덱 집합의 총합**을 최적화한다.
- 같은 캐릭터의 장비 변경은 개인 피해, 동료 버프, 생존, 덱 재배치까지 다시 평가한다. OL의 기대 효율은 전체 목표값의 차이로 구한다.
- 동일 입력의 결정적 실행을 N번 반복해도 신뢰도는 늘지 않는다. 어떤 난수(크리·명중·조작 등)를 모델링하는지 명시하고, 모델 자체의 오차와 표본 오차를 구분해야 한다.

공식 전투력은 목록 정렬·계정 비교에 사용할 수 있지만 레이드 대미지의 대리값으로 삼지 않는다. 전투력 차이에 따른 보정도 적용 모드별 규칙이며 다른 콘텐츠에서 가져와 솔로 챌린지에 적용하지 않는다.

## 10. 다음 구현·실측에 사용할 순서

기존 [P00~P09 계획](implementation-plan.ko.md)을 교체하는 새 단계가 아니라, 조사로 확인한 보강 순서다.

1. **자료의 의미 고정:** 이벤트·대상·기준 스탯·타격 종류·단위·버전·미지원 상태를 먼저 보존한다. 위 충돌 항목을 검증 대기 목록으로 사용한다.
2. **현재 5인 실측 대조:** 단발 숫자뿐 아니라 탄 소비/명중 횟수, 버프의 수혜자와 시간, 무기 교체 전후를 맞춘다. 히트 정수화 후보를 비교한다.
3. **P04 팀 사이클:** 게이지 → 단계별 시전 → 풀버스트 → 종료 → 재충전 전체를 실제 이벤트로 연결한다. 리타 쿨감·블랑 종료 조건·모더니아 지속시간을 함께 확인한다.
4. **P05 보스와 조작:** 방어력 구간, 파츠·코어·저지, 명중, 생존, 수동 조작 정책을 연결한다. 총합만 맞추기 위한 임의 보정 계수는 도입하지 않는다.
5. **큐브·애장품의 적용 범위 확대:** 누락 효과를 조용히 무시한 덱을 추천 후보에 넣지 않는다. 필요한 로스터를 지원 범위별로 확장한다.
6. **반복 통계 → 비중복 5덱 → OL 행동별 효율:** 모델 대조를 마친 뒤 표본을 늘린다. 평균 증가뿐 아니라 목표 초과 확률·재시도 시간·재료 소모를 비교한다. 유니온 3덱은 후순위다.

영상·로그의 요구 조건은 [기존 측정 안내](p03-measurement-guide.ko.md)를 따른다. 전체 결과 로그는 합계를, 영상은 발동·조준·기믹의 시간축을 보완한다. 4~5분 영상이라도 계정 스냅샷과 전투 조건을 함께 묶어야 한다. 이 문서 작성 중 새 실게임 측정은 수행하지 않았다.
