# P01 → P02 인계

## 입력 기반

P01 실제 수집과 저장 대조는 193명을 대상으로 완료했다. 정본은 AccountSnapshot + GameSnapshot ID다. 개인정보/개별 육성 수치는 이 문서에 복사하지 않으며 로컬 저장소에서 조회한다.

P02는 이 입력에서 기존 C# StatCalculator를 적용한다. 계정의 원천/동기화 레벨과 Solo Raid 시나리오 레벨을 구분하고, OL의 원천 단위와 정규화 단위를 다시 변환하지 않는다. 특히 API Integer로 인코딩된 크리티컬·크리티컬 대미지·차지 대미지는 이미 비율로 정규화되어 있다.

## 최소 검산 덱 후보

리타 / 블랑 / 누아르 / 앨리스 / 모더니아를 입력·무기·스킬 검증 후보로 둔다. 고정 upstream 목록상 버스트는 1/2/3/3/3이며 SMG/AR/SG/SR/MG 입력을 포함한다. 실전 최적 덱 추천이 아니라 단계별 회귀 검증 후보이다.

| 구성원 | P02 입력/무기 검증 대상 | C# 전투 지원 상태 |
|---|---|---|
| 리타 | SMG, 기초 스탯·스킬 입력 | 미구현/미평가 |
| 블랑 | AR, 장비·큐브·소장품 입력 | 미구현/미평가 |
| 누아르 | SG, 다중 히트 입력과 장비 보존 | 미구현/미평가 |
| 앨리스 | SR, 차지 배율·가산 및 차지 시간 | 미구현/미평가 |
| 모더니아 | MG, 사격 시간·탄약 입력 | 미구현/미평가 |

세부 effect 지원표는 P03에서 실제 translator/runtime 구현과 테스트를 연결해 확장한다. 블랑/누아르 등 캐릭터 상호작용과 팀 버스트는 단순 입력 성공으로 지원 처리하지 않는다. P01 카탈로그 200명은 표시 매핑 범위이며 검증된 5덱 로스터 25명이라는 뜻이 아니다.

## 첫 보스 후보

개발용 원천 후보는 기존 `solo_raid_boss.json`의 **season 3 / code bbg001**이다. 해당 테이블에서 파츠 3개와 원천 스킬 항목 30개를 확인했다. 최신 시즌 보스나 현재 추천 대상을 뜻하지 않는다. 원천을 고정한 상태에서 P05에 파츠·기믹·시간 축을 분석하고, 검증에 필요한 관측이 부족하면 검증 가능한 보스로 변경한다.

P02 단일 히트 계산에서는 우선 통제된 고정 표적 fixture를 사용한다. 위 보스의 실전 기믹을 생략한 결과를 Solo Raid 추천 표본으로 저장하지 않는다.

## 유지할 결정

- 기초 스탯은 사용자 실게임 검증을 받은 기존 C# 기준.
- 차지는 `기본 × (1 + 배율 증가분 합) + 가산 합`.
- 히트 정수화는 후보식 비교 후 판정.
- 버스트는 실제 팀 게이지와 사이클 완성이 목표.
- CSV는 보조 경로로 후순위. 개인 입력은 동기화 snapshot을 기본으로 사용.
