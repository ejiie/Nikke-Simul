## 2. 세부 기능 구현

### 2.1 앨리스 시간별 발당 피해 로그 (Damage Log)
1. **기본 대상 및 대상 전환**:
   - 현재 편성 내에 앨리스(5004)가 포함된 경우 기본 대상 니케로 앨리스를 자동 선택합니다.
   - 드롭다운 셀렉터를 통해 편성 내 다른 니케(모더니아, 누아르, 블랑, 리타 등)로 즉시 전환하여 해당 니케의 발당 피해 로그를 열람할 수 있습니다.
2. **시간별 발당 피해 인터랙티브 SVG 그래프**:
   - X축: 0~180초 시간축 (엔진 최대 상한 180초/10800프레임 기준).
   - Y축: 발당 대미지 (만 단위 눈금 표시).
   - **자체 버스트 효과 활성 구간 vs 팀 풀버스트 구간 시각적 구분**:
     - 자체 버스트 활성 구간 (앨리스 버스트 스킬 10초 활성): 호박색/오렌지빛 반투명 밴드 (`.band-self-burst`).
     - 팀 풀버스트 구간 (10초): 시안/스카이블루 반투명 밴드 (`.band-team-burst`).
     - 두 효과 중첩 구간: 보랏빛 중첩 블렌딩 밴드로 표시되며 상단 범례(Legend)와 명확히 매핑.
   - 타격 포인트 마커:
     - 풀차지(반경 4.5) vs 비풀차지(반경 3.0) 구분.
     - 크리티컬(붉은색) vs 일반(푸른색) 구분.
     - 코어 명중 시 테두리 금색 하이라이트.
   - 호버 툴팁: 타격 시간(초), 발당 대미지, 크리/코어/풀차지/자체버스트/팀풀버스트 상태를 실시간 표시.
   - 클릭 연동: 그래프 점 클릭 시 하단 상세 표의 해당 타격 행을 선택하고 계산 근거를 즉시 엽니다.
3. **누적 대미지 및 요약 통계**:
   - 해당 니케 총 피해량, 발사(히트) 횟수, 평균 발당 피해, 크리티컬/코어 적중률, 풀차지 비율을 카드 그리드로 표시.
   - 그래프 배경에 은은한 점선 곡선으로 누적 피해 추세를 함께 렌더링.
4. **상세 표 및 인터랙티브 필터**:
   - 버스트 상태 필터: `[전체]`, `[자체 버스트만]`, `[팀 풀버스트만]`, `[중첩 구간만]`, `[비버스트 평타]`.
   - 타격 종류 필터: `[전체]`, `[풀차지]`, `[비풀차지]`, `[크리티컬]`, `[코어 명중]`.
   - 테이블 컬럼: 시간(초/프레임), 발사 식별자(#shotId), 발당 피해, 누적 피해, 차지 상태(풀차지 여부 및 %비율), 판정(크리/코어), 버스트 활성 상태, [근거 보기] 버튼.
5. **발당 계산 근거 열람 (Damage Audit Panel)**:
   - 특정 타격의 [근거 보기] 클릭 시 상세 패널 오픈:
     - 기초 공격력 (Base ATK)
     - 버프 적용 공격력 (Buffed ATK)
     - 적 적용 방어력 (Target DEF)
     - 타격 공방차 (ATK - DEF)
     - 스킬 계수 (%)
     - 차지 배율 (x배)
     - 크리티컬 배율 (x배)
     - 코어 타격 배율 (x배)
     - 팀 풀버스트 보너스 (x배)
     - 적용 정수화 정책 (final_round_even 등)
     - 유효 버프 목록: 버프 출처(예: 리타 스킬1, 누아르 스킬2, 앨리스 버스트), 버프 종류, 증가율, 잔여 프레임(또는 상시) 표시.
6. **JSON / CSV 내보내기**:
   - `JSON 내보내기`: 메타데이터(스냅샷 ID, 계정, 규칙 버전, 실행 조건, 버스트 전술 설정) + 발당 타격 로그 전체 배열을 JSON 파일로 브라우저 즉시 다운로드.
   - `CSV 내보내기`: RFC 4180 호환, UTF-8 BOM 포함 CSV 파일 다운로드.

### 2.2 버스트 사용 니케·우선순위·순환 설정 (Burst Tactics)
1. **현재 편성 기반 사용 허용 체크 (Allowlist)**:
   - 편성 슬롯(1~5)에 등록된 니케들만 I, II, III 단계별 카드로 자동 배치.
   - 니케별 발동 허용 체크박스 제공. 체크 해제된 니케는 발동에서 완전히 제외되며, `next_ready` 대체 후보에도 포함되지 않습니다.
2. **"앨리스 우선" vs "앨리스만 사용"의 명확한 구분**:
   - **앨리스만 사용 (Alice Only)**: 앨리스만 허용 체크 ON, 다른 모든 버스트 III 니케는 허용 체크 OFF (발동 제외). 앨리스 쿨다운 중에는 다른 3버스트 니케가 발동되지 않습니다.
   - **앨리스 우선 (Alice First)**: 모든 버스트 III 니케가 허용 체크 ON이지만, 우선순위에서 앨리스가 1순위로 배치되며 교대 순환 모드가 적용됩니다.
   - 상단에 **[앨리스만 사용]**, **[앨리스 우선]**, **[편성 순서대로]** 3종의 원클릭 프리셋 버튼 제공.
3. **단계별 후보 순위 (Priority Reordering)**:
   - I단계, II단계, III단계 각각에 대해 후보 니케 목록에 순위 배지(1순위, 2순위...) 표시.
   - ▲, ▼ 버튼을 통해 단계 내 우선순위를 자유롭게 재배치.
4. **III단계 순환 정책 및 첫 시전자**:
   - 모드: `교대 순환 (alternate)` vs `우선순위 고정 (priority_only)`.
   - 첫 시전자 (`first_caster`): 버스트 III 허용 후보 중 최초 1회차에 발동할 니케 지정.
5. **쿨다운/미준비 시 Fallback 정책**:
   - `next_ready`: 우선 니케가 쿨다운 중이면 준비된 다음 허용 니케 발동 (단, 제외된 니케는 절대 미발동).
   - `wait_preferred`: 우선 니케의 쿨다운이 끝날 때까지 대기.
6. **설정 저장 및 복원**:
   - 계정/편성 ID 단위로 로컬 스토리지에 자동 저장 및 복원.
7. **실제 버스트 발동 vs 설정 대조 뷰 (Cross-comparison)**:
   - 시뮬레이션 결과 수신 시, 각 풀버스트 회차별 실제 시전자, 시작/종료 시각, 그리고 사용자가 설정한 전술에 부합하는지 여부(설정 일치 / 대체·대기 발생)를 대조 테이블로 렌더링.

### 2.3 180초 엔진 한도 및 상태 진단 (Badges & Diagnostics)
1. **180초 엔진 한도 연동**:
   - 전투 조건의 시간(초) input에 `max="180"` 제약을 적용하고 초과 입력을 방지. 안내 문구 추가.
2. **편성 변경 후 Stale ID 감지**:
   - 이전 편성에 저장된 전술 설정의 니케 ID가 현재 편성에 존재하지 않는 경우 `[주의] 제외된 니케가 버스트 설정에 남아 있습니다` 경고 배너 및 `[제외된 니케 설정 정리]` 버튼 노출.
3. **잘못된 단계 및 불완전 설정 감지**:
   - 편성에 버스트 I, II, III 중 특정 단계가 누락된 경우 경고 배너 노출 (`missing_stage`).
   - 특정 단계의 모든 니케가 발동 제외로 설정된 경우 버스트 차단 경고 노출 (`all_disabled_stage`).
4. **잠정 정확도 상태 표시**:
   - 모든 화면 상단에 `잠정 정확도 · 실게임 관측 대조 전 합성 시뮬레이션` 상태 뱃지 유지.
   - 로그 어댑터 동작 모드 (`합성 Fixture (E1/B1 계약 대기 Adapter)` vs `서버 로그 연동`) 명시.
   - 타임라인 상한 도달 시 `로그 상한 도달 (잘림 발생)` 뱃지 표시.

## 4. 잔여 의존성 및 향후 계획

- **E1/B1 계약 대기**:
  - 현재 UI는 `damage-log-adapter.js`를 통해 명시적인 mock fixture 및 경계 인터페이스로 동작하고 있습니다.
  - E1의 `docs/damage-log-engine-contract.ko.md` 및 B1의 `docs/damage-log-api-contract.ko.md`가 확정되고 실제 API 엔드포인트가 제공되면, `fetchDamageLog`가 자동으로 서버 응답(`replayData.damageLogs` 또는 `/api/runtime/skill-replays/{id}/damage-log`)을 수신하여 표시하도록 준비되어 있습니다.
- **실게임 관측값 대조**:
  - 본 화면에 표시되는 발당 수치 및 그래프는 합성 시뮬레이션 기준이며, 게임 실측 데이터 수신 시까지 잠정 정확도 배지를 유지합니다.
