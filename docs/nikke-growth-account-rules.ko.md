# 니케 성장·콘솔·큐브 표시 규칙

확인일: 2026-09-09. 이번 조사는 성장·계정 화면과 연결되는 규칙을 대상으로 한다. 게임 전체의 대미지 계산을 검증했다는 의미는 아니다.

## 돌파와 코어 강화

- SSR은 3회 한계돌파 후 코어 강화가 이어진다. 별 표시와 코어 강화는 서로를 대체하지 않는다. SR은 최대 2회 돌파, R은 돌파 불가이므로 SSR의 성장 규칙을 다른 희귀도에 일반화하지 않는다. [Prydwen 성장 가이드](https://www.prydwen.gg/nikke/guides/character-progression/)
- 블라블라 공개 코드에서도 grade와 core를 구분한다. 공개 cube-icon-CVdKq4Pn.js의 W 함수와 캐릭터 성장 계산 부분을 대조했다. [공식 블라블라 코드](https://www.blablalink.com/assets/nikke/version/default/assets/cube-icon-CVdKq4Pn.js)
- 이 앱의 SSR 상세 UI는 별 3칸을 먼저 표시하고, 코어 값이 1 이상일 때만 오른쪽에 코어 UI를 표시한다. 7코강은 MAX다. 코어가 있으면 별 3개를 채운 상태로 표시한다. 계산용 원본 스냅샷을 고치지는 않는다.
- 별이 읽기 전용이라는 이유로 흐리게 처리되어 미돌파처럼 보이지 않도록 별 이미지의 불투명도를 유지한다.

## 콘솔

- 공용, 화력형·방어형·지원형, 엘리시온·미실리스·테트라·필그림·어브노멀의 9종을 계정 공통 연구 레벨로 관리한다.
- 사용자 요청에 따라 Local Lab 콘솔 카드에서 수치 표시는 레벨만 유지한다. 누적 경험치 입력은 제외한다. 미수집 값을 0으로 만들어 표시하거나 저장하지 않는다.
- 이미지는 Local Lab materialize-nll-console-presentation-assets.ps1과 같은 게임 원본 아이콘을 사용한다. 배포 경로는 공식 호스트가 아닌 nikke.gg / static.dotgg.gg의 원본 아트 미러다. 공용 연구 아이콘은 RE-Energy다. 각 다운로드 URL과 SHA-256은 account-presentation.json에 기록한다.

## 하모니 큐브

- 계정 공통 큐브 레벨과 캐릭터의 장착 큐브 ID를 구분한다. 계정에서 큐브 레벨을 바꾸면 해당 큐브를 장착한 모든 캐릭터의 저장 빌드에도 반영한다. 다른 큐브를 장착한 캐릭터에는 적용하지 않는다.
- 한국어 이름·레벨별 고유 효과·레벨 범위·아이콘 resource ID는 공식 블라블라 equip/ko/cube_<id>.json에서 읽는다. 이미지 경로는 공식 웹 코드의 ICONS_URL 규칙을 따른다. [공식 공개 앱 코드](https://www.blablalink.com/assets/nikke/version/default/assets/index-CH1j4QFW.js)
- 현재 준비된 계산 자료에 대응하는 16종을 표시한다. 카탈로그에 있다는 사실을 보유 또는 최대 레벨의 증거로 취급하지 않는다. 기존 저장 데이터는 장착 캐릭터의 관측 레벨을 사용하고, 관측이 없으면 미확인으로 표시한다.
- Save는 새 스냅샷을 생성한다. 과거 스냅샷을 수정하지 않는다. 재수집으로 실제 큐브 레벨을 얻으면 그 값을 우선한다. 재수집에서도 미확인인 큐브만 기존 수동 보완값을 유지한다.

## 확인 결과와 출처

- 콘솔 9종·큐브 16종 이미지 표시, 큐브 변경 요청, 0·1·7코강 분기, 폭 1500·850·500px에서 별과 코어의 가로 배치를 브라우저로 확인했다.
- 실제 계정에 테스트값을 저장하지 않았다. 브라우저 저장 요청은 가로채어 내용만 검증했고, 영속 저장·과거 스냅샷 보존·수집값 우선순위는 테스트 전용 저장소에서 검증했다.
- Local Lab UI 출처 커밋: c05fc1c392a523b9e17ebe0cbd4811bed9c19adb. 계정 카드 마크업과 CSS를 재사용했고, 경험치 제외 및 성장 배치는 이번 사용자 지시에 따른 변경이다.
