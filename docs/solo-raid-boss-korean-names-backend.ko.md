## 조사와 원천 보존

한국어 나무위키 미러의 **역대 솔로 레이드 보스** 표에서 시즌1~39의 번호와 이름을 직접 대조했다. 원 나무위키는 웹 읽기 실패, 미러의 직접 Python 요청은403이었고 웹 읽기에 제공된 미러 본문을 확인했다. 원문 나무위키 직접 조회에 성공했다고 주장하지 않는다. 접근 제한을 우회하지 않았다.

한국어 기사·시즌별 커뮤니티 제목·공식 공지 아카이브 및 기존 한국어 공개 보스 목록을 대조했다. 원천 URL·확인 시각·영문명·원천ID·사용자 확인·다른 표기·채택 근거는 **[내부 이름 manifest](../tools/data-pipeline/manifests/solo-raid-korean-names.manifest.json)** 에만 기록했다. 일반 보고서·UI에는 원천 URL·확인 시각을 나열하지 않는다. 한국어 공개 목록은 공개 bosses 레코드만 재조회했으며 계정·개인 덱 조회 없음.

준비 시 웹 문서의 가변 HTML/JavaScript를 다시 추출해 이름을 바꾸지 않고, 검토한 내부 manifest의 원문 이름을 사용한다. enikk의 시즌 번호·영문 원본명·이미지 원천ID가 검토값과 모두 일치할 때만 이름을 연결한다. 새 시즌 또는 원천 식별 변경은 `korean_name_unavailable`로 남긴다. 시즌 번호나 영어 이름만 같다는 이유로 이름을 복사하지 않는다. manifest에는 채택한 원천에 그 이름이 실제 기록되어 있는지도 검사한다.

## API와 준비 결과

GET `/api/presentation/solo-raid-bosses`의 wire 형식은 유지된다. `schemaVersion:1`, `defaultBossId:dummy`, `bosses`43개(더미+시즌1~42), `diagnostics:[]`, `complete:true`. 각 보스 필드는 계속 `id/name/imageUrl/season`뿐이다.

확인한 변경값:
- `solo-raid-37.name = 울트라`
- `solo-raid-42.name = 앨트루이아`
- `solo-raid-35.name = 크리스탈 체임버`

`bossId`·정렬·이미지 경로 형식·계산/저장 계약 변경 없음. 이름 미확인 오류 코드는 기존 `korean_name_unavailable` 유지. 장래 누락의 message는 `한국어 시즌 대응 미확인`, 식별 변경은 `원천 보스 식별 변경으로 한국어 시즌 대응 재확인 필요`로 이유를 구체화했다. 이미지 실패는 기존 `boss_image_unavailable`.

격리 산출물: `artifacts/bfix3/data/presentation/`. 생성된 `solo-raid-bosses.manifest.json` 안에 내부 이름 manifest와 준비 시각·원천 query hash·각 이미지 hash를 보존한다. 이 파일은 정적 assets 바깥이다.

```powershell
python tools/data-pipeline/prepare_solo_raid_bosses.py --presentation-root artifacts/bfix3/data/presentation
```

준비 출력: `displayed:43, excluded:0, complete:true`. 이미지42개 준비. Git 제외 이미지/카탈로그는 merge만으로 원본 배포에 반영되지 않으며 Director 배포 단계에서 별도 준비가 필요하다.
